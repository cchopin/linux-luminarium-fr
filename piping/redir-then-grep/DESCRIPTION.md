On sait lancer des commandes, rediriger leur sortie (par exemple avec `>`), et chercher dans le fichier obtenu (par exemple avec `grep`).
Assemblons tout cela !

Pour préparer les niveaux plus complexes, il faut :

1. Rediriger la sortie de `/challenge/run` vers `/tmp/data.txt`.
2. Cela produit cent mille lignes de texte, dont une contient le flag, dans `/tmp/data.txt`.
3. Chercher le flag dans ce fichier avec `grep` !
