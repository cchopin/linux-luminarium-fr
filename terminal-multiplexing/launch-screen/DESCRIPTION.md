Entrons tout de suite dans le vif du sujet !

`screen` est un programme qui crée des terminaux virtuels à l'intérieur du terminal.
C'est un peu comme avoir plusieurs onglets de navigateur, mais pour la ligne de commande !

Lancer screen est très simple :

```console
hacker@dojo:~$ screen
```

C'est tout !
On se retrouve alors dans une session screen.
Elle ressemble _exactement_ à un terminal, mais elle offre de nouvelles fonctionnalités à découvrir.

Dans ce défi, il suffit de lancer screen pour obtenir le flag.
Facile !

----
**NOTE :**
Quand on a fini avec la ligne de commande, on tape `exit` ou on appuie sur `Ctrl-D` pour quitter la session screen.
Screen se termine alors et rend le shell *d'origine*.
