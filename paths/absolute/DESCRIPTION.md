Explorons un chemin un peu plus compliqué !
Sauf dans le niveau précédent, les défis de pwn.college se trouvent dans le répertoire `challenge`, lui-même placé directement dans le répertoire racine (`/`).
Le chemin du répertoire `challenge` est donc `/challenge`.
Le programme du défi s'appelle `run` et se trouve dans le répertoire `/challenge`.
Le chemin du programme `run` est donc `/challenge/run`.

Ce défi demande encore d'exécuter le programme en invoquant son chemin absolu.
Il faut exécuter le fichier `run` qui se trouve dans le répertoire `challenge`, lui-même placé dans `/`.
Si on lance correctement le programme, il affiche le flag.
Bonne chance !
