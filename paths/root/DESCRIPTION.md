Le système de fichiers commence donc à `/`.
Sous cette racine se trouve un grand nombre d'autres répertoires, de fichiers de configuration, de programmes et, surtout, de _flags_.
Dans ce niveau, un programme nommé `pwn` a été placé directement dans `/` : il donne le flag.
Il suffit donc d'exécuter ce programme !

On lance un programme en indiquant son chemin sur la ligne de commande.
Ici, on donne le chemin exact à partir de `/`, donc le chemin est `/pwn`.
Ce type de chemin, qui commence à la racine, s'appelle un « chemin absolu ».

Démarrer le défi, ouvrir un terminal, lancer le programme `pwn` avec son chemin absolu, et capturer ce flag !
Bonne chance !
