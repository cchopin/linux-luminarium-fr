Croit-on maîtriser `chmod` ?
Entraînons-nous !

Ce défi demande de modifier, plusieurs fois de suite, les permissions du fichier `/challenge/pwn` de manières précises.
Si une permission est fausse, le jeu se réinitialise, et l'on peut recommencer.
Si l'on réussit huit fois de suite, le défi permet d'utiliser `chmod` sur `/flag` pour le rendre lisible par soi-même :-)
Lancer `/challenge/run` pour commencer !
