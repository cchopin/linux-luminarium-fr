On tape beaucoup de commandes, et les ressaisir entièrement peut vite devenir pénible.
Heureusement, le shell enregistre un _historique_ de chaque commande exécutée.

On peut parcourir ces commandes enregistrées avec les flèches haut et bas, et c'est ce qu'on va s'entraîner à faire dans ce défi.
Ce défi injecte le flag dans l'historique.
Ouvrir un terminal, appuyer sur la flèche haut et récupérer le flag !
Dans les autres défis, l'historique contiendra le journal des commandes déjà exécutées : si l'on doit relancer une commande semblable, il suffit de parcourir l'historique avec les flèches pour la retrouver !
