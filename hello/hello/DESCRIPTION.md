Dans ce défi, on saisit sa première commande !
Lorsqu'on tape une commande puis qu'on appuie sur Entrée, la commande est exécutée, comme ceci :

```console
hacker@dojo:~$ whoami
hacker
hacker@dojo:~$
```

Ici, l'utilisateur a exécuté la commande `whoami`, qui affiche simplement le nom d'utilisateur (`hacker`) dans le terminal.
Une fois la commande terminée, le shell affiche à nouveau le prompt, prêt pour la commande suivante.

Dans ce niveau, il faut exécuter la commande `hello` pour obtenir le flag !
Attention : les commandes sous Linux sont sensibles à la casse : `hello` est différent de `HELLO`.
