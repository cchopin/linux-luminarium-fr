Ce niveau est délicat : il cache la page de manuel du défi en randomisant son nom.
Heureusement, toutes les pages de manuel sont rassemblées dans une base consultable : on peut donc chercher dans cette base la page cachée !
Pour savoir comment chercher correctement, il faut lire la page de manuel de `man` avec la commande `man man` !

---
**INDICE 1 :** `man man` présente l'usage avancé de la commande `man` elle-même. Il faut utiliser ces connaissances pour trouver comment chercher la page de manuel cachée qui explique comment utiliser `/challenge/challenge`.

**INDICE 2 :** même si la page de manuel porte un nom aléatoire, c'est bien `/challenge/challenge` qu'il faut utiliser pour obtenir le flag.
