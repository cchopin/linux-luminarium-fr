Certains programmes n'ont pas de page de manuel, mais peuvent indiquer comment les utiliser lorsqu'on les lance avec un argument spécial.
En général, cet argument est `--help`, mais il peut souvent être `-h` ou, plus rarement, `-?`, `help`, ou d'autres valeurs plus étranges comme `/?` (cette dernière se rencontre plutôt sous Windows).

Dans ce niveau, on s'entraîne à lire l'aide d'un programme avec `--help`.
Essayons !
