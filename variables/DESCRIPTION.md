La ligne de commande Linux est en réalité un langage de programmation sophistiqué, avec lequel on peut écrire de vrais programmes !
Comme l'interface en ligne de commande est couramment appelée « shell », les programmes écrits dans ce langage sont appelés des « scripts shell ».
Quand on utilise la ligne de commande, on écrit en fait un script shell, ligne après ligne !

Comme la plupart des langages de programmation, le shell gère les variables.
Ce module permet de se familiariser avec leur définition, leur affichage et leur utilisation !
